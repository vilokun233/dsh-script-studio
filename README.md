# 剧本创作 · Script studio

DeepSeek Harness（DSH）插件：在侧栏加一个「剧本创作」入口，四种模式各有各的表单，点一下就把带完整铁律的本批指令发进一个会话，让模型按批把竖屏短剧剧本写出来。

它不是一个"提示词生成器"——信息填完点「开始生成剧本」，插件会自己建会话、发指令、开写；写完一批回来点「继续下一批」。

## 四种模式

| 模式 | 你要填的 | 它会做什么 |
| --- | --- | --- |
| **原创剧本** | 设定包：一句话故事、主角、反派/对抗力量、世界观硬规则、情感线、核心事件、爽点机制、主要配角、补充要求；市场+平台、题材、集数、每批集数 | 先出全剧分集大纲，再按批写正文（蓝图 → 正文 → 自检清单） |
| **小说改剧本** | 小说正文（可上传 `.txt/.md/.srt`）、改编范围（如 第 1–20 章）、目标集数、改编程度（忠于原著/适度改编/大幅重构） | 分集大纲标注对应原著章节，按小说→剧本转译红线逐批转译 |
| **剧本改剧本** | 待转置剧本、来源市场 → 目标市场（国内转海外 / 国内转国内）、目标平台、目标集数、转置设定（人名地名/场景背景/文化梗/台词/节奏/集数） | 逐集给「转置蓝图 + 与源集的对应关系 + 改了什么」→ 正文 → 改动说明 |
| **剧本润色** | 剧本（自动按「第X集」拆开，勾选要改的集）、润色方向（台词/动作描写/剧本格式/节奏/情绪/钩子）、润色强度 | 只对选中集逐集润色 + 改动说明，禁止改剧情、加新场 |

市场分**国内 / 海外**，平台各一套：

- 国内：抖音、快手、视频号、红果、其他
- 海外：ReelShort、DramaBox、其他

选中平台后，页面会直接显示该平台的规格与 4–6 条方向提示（题材偏好、节奏、爽点、本地化、合规红线），这些也会写进指令。

## 安装

前提：DSH 的当前版本（插件用到 Client 的 `slots`、`locale`、`uiWorkspace`、`workspaces`、`sessions` 五个服务）。

**方式 A：插件页安装本地目录**

1. 把本目录放到任意位置（例如 `Documents/dsh-script-studio`）
2. 打开 DSH → 设置 → 插件 → 添加插件 → 选择这个目录
3. 装好后侧栏「插件」下面出现「剧本创作」

**方式 B：从 GitHub 克隆再安装**

```powershell
git clone https://github.com/<you>/dsh-script-studio.git
# 然后在 DSH 插件页添加本地目录，指向 clone 出来的文件夹
```

安装后如需刷新页面（Client 插件热更新接收器没在跑时），刷新一次即可。

## 使用

1. 选一个模式
2. 填素材与选项（每种模式要填的不一样，见上表）
3. 想改指令的话，展开底部「本批指令（可编辑）」直接改
4. 点「开始生成剧本」——插件会：
   - 没有工作区时先让你选一个文件夹并注册为工作区
   - 新建（或复用）一个会话，跳到该会话
   - 把工作指令作为用户消息直接发进去
5. 模型按批输出「蓝图 → 正文 → 自检清单」，写完本批自动停下
6. 回侧栏点「继续下一批」，它会往同一个会话发「继续第 11–20 集…」

失败时会显示红字；「复制指令」可把当前这批指令复制走手动发送。

## 指令里有什么

- **角色定位**：短剧节奏架构师 + 5 条核心能力
- **最高优先级铁律**：版权、合规、投流、节奏 + 漫剧制作红线 + 小说→剧本转译红线
- **项目规格**：市场、平台、题材、集数、制作约束、目标市场写法
- **平台方向**：该平台的规格与方向提示
- **素材**：你在表单里填的每一块
- **本批任务**：本批集数范围、首批/续写规则、每集输出顺序
- **写作铁律 + 视听化写作铁律**：上半身动作、镜头/场景上限、钩子规则、三类禁止写进舞台指示
- **输出格式**：蓝图模板、正文模板、自检清单
- **执行纪律**：写满即停、材料不足先提问

## 已知限制

- 指令正文是**中文**（方法论术语），海外市场会在指令里要求用英文写剧本
- 「开始生成剧本」通过 `ctx.sessions.using(...).binding.session.prompt(...)` 直接发送消息，属于 Client 侧会话接口；DSH 大版本升级后这个调用可能需要复核
- 表单内容只存在内存里（切走再回来不丢，刷新页面会清空）
- 没有遥测，不读取会话内容；关闭插件后入口与页面一并移除

## 开发

改完 `client.js` 后在插件页把 Script studio 禁用再启用，浏览器会加载新的一份；不生效就刷新页面。
